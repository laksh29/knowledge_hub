# sqlite_wal_fts_toolkit

Generic WAL-mode SQLite database opener and FTS5 virtual-table/trigger SQL
builders, parameterized only by file/table/column names.

Zero dependency on any consuming application's domain types — copyable
verbatim into any Flutter/Dart project per `flutter-clean-architecture-guide.md`
§3.1's "zero project context" test.

Currently a scaffolded, empty placeholder — implementation lands in the
`notes-mvp` feature's task 1.3.
